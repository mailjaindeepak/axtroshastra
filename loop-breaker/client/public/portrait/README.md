Drop your cover art here:

- `home.jpg` — full-height portrait used on the Home / Profile page
- `episodes.jpg` — portrait used on the Episodes page

Any image works (jpg/png/webp — just keep the filename, or update the `src`
in `PortraitPanel.tsx` if you rename it). Until a file exists, the panel
shows a placeholder gradient with the character's initial instead of
breaking.
