# IQ Test Report — Section Spec

Product slug: `iq_test`
Route: `/en/iq-test`
Price: ₹499
Theme: Shared `_VYAPAR_CSS` / `_VYAPAR_DEFS` (card-per-page, 430×830px)
No astrology, no LLM narrative — purely answer-driven scoring.

## Teaser (free, pre-payment)

Shown on the landing page after quiz submission:
- **IQ Score** — the number (e.g. 117)
- **Classification** — e.g. "Above Average"
- **Percentile** — e.g. 87th percentile
- **Highlight 1** — top-performing category, positive framing (e.g. "Exceptional pattern recognition skills")
- **Highlight 2** — second strength or notable trait

Nothing else. No category breakdown, no profile, no recommendations.

## Full Report (paid, 11 pages)

### Page 1 — Cover
- Name, date of assessment
- "IQ Assessment Report"
- Axtroshastra branding/logo

### Page 2 — A Note for You
Welded page (same on every report, not personalized). Warm, encouraging intro:
- What this report measures
- IQ is one dimension of intelligence, not a ceiling
- How to read the report
- Approachable, not clinical

### Page 3 — Your IQ Score
The centrepiece page:
- Large score display (prominent number)
- Classification badge (Below Average / Average / Above Average / Superior / Exceptional)
- Percentile bar visualization — "You scored higher than X% of test-takers"
- One-line interpretation of what this score range means

### Page 4 — Pattern Recognition
Category breakdown card:
- Score: X/5 correct
- Percentage bar visualization
- Label (Exceptional / Strong / Moderate / Developing)
- 2-3 sentence interpretation: what pattern recognition means, how this score reflects the person's ability, real-world relevance (problem-solving, seeing trends, strategic thinking)

### Page 5 — Logical Reasoning
Same structure as Page 4:
- Score, bar, label
- Interpretation: deductive thinking, if-then reasoning, decision-making clarity

### Page 6 — Verbal & Analogical Thinking
Same structure:
- Score, bar, label
- Interpretation: language processing, relationship mapping, communication strength

### Page 7 — Classification Ability
Same structure (odd-one-out category):
- Score, bar, label
- Interpretation: categorization, identifying exceptions, analytical sorting

### Page 8 — Cognitive Strengths
- Top 2-3 strengths drawn from highest-scoring categories
- Each strength: title, description, real-world applications (career, learning, daily life)
- Positive, encouraging tone — "Your brain excels at..."

### Page 9 — Growth Areas & Recommendations
- 2-3 areas for improvement drawn from lower-scoring categories
- Each area: what it means, why it matters, 2 specific actionable tips
- Framed as growth opportunities, not weaknesses
- Concrete: "Try daily number puzzles for 10 minutes" not "improve your numerical ability"

### Page 10 — Your Learning Style
- Based on the pattern of category scores
- Maps to a learning style description (e.g. "Visual-Logical Learner" if pattern + logic are strong)
- How the person absorbs information best
- Study/work environment tips tailored to their style

### Page 11 — Methodology & Thank You
Split page:
- Top half: brief methodology explanation — how scoring works, age-norming, what IQ measures and doesn't measure, scientific credibility without being dry
- Bottom half: thank you, Axtroshastra branding, "share with friends" nudge
