OTP logins

Who requested a login code, when, and whether it went out. We use this to spot delivery problems — never to read anyone’s code.

Security: the login code is never shown here, and for real logins it isn’t even stored — Message Central generates and checks it. Showing codes would let anyone with admin access log in as any user, so we don’t.
